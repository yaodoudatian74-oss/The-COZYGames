# ひだまり島 (Hidamari Island)

島の季節をめぐらせる、3Dのスローライフゲームです。釣り・虫とり・畑・料理・家づくりを楽しみながら、島に散らばった「ひかりのかけら」を集めます。

- **あつ森風の雰囲気**: 丸くやわらかい造形、やさしい色、季節と昼夜で変わる空と草木
- **オリジナルのストーリー**: 嵐の夜に流れ着いた主人公が、島の季節を揃える4章の物語
- **コンテンツ数**

| 分類 | 数 | 中身 |
|---|---|---|
| 家具 | 500 | 25種類 × 20色 |
| 魚 | 400 | 20種 × 20バリエーション（川・池・海） |
| 虫 | 400 | 25種 × 16色（季節と昼夜で出現が変わる） |
| 料理 | 400 | 20種類 × 20風味（材料はポーチから自動で選ぶ） |
| 農作物 | 400 | 20種 × 20品種（種から育てる） |
| 鉱石 | 400 | 20種 × 20の味（岩をほって手に入る） |
| 木材 | 400 | 20種 × 20の味（木を切って手に入る） |

## 遊び方

### 操作

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー（Shiftで走る） | 左下のパッド |
| 決定・話す・釣る・つかまえる | Space / Enter | 右下の○ |
| カメラ回転 | Q / E、または画面をドラッグ | 画面をドラッグ |
| ポーチ / ノート / メニュー | P / N / M | 右上のボタン |
| 家具をまわす・やめる（配置中） | R / Esc | 画面下の「まわす」「やめる」 |

### 基本の流れ

1. **釣り**: 川・池・海の水辺に向かって決定キー。うきが沈んだら、もう一度決定キーで釣り上げます。季節・時間・場所で釣れる魚が変わります。
2. **虫とり**: 近づくと逃げる虫に向かって決定キー。飛ぶ虫ほど逃げやすいです。木を揺らすと虫が落ちてくることもあります。
3. **畑**: 空き地で「たがやす」→ たねをまく → 水をあげる。翌日に水をあげた畑が育ちます。収穫は「しゅうかく」。たねはポーチから「まく用にえらぶ」で選べます（作物には育つ季節があります）。
4. **料理**: 家の中のかまどで、ポーチの材料（魚・虫・野菜・果物・穀物・ハーブ）を使って料理します。
5. **家づくり**: 家の中で家具を買って（モコのお店）おけます。
6. **採掘**: 岩に向かって「ほる」。つるはしが必要です。岩は3回ほると壊れ、鉱石（400種）が出ます。2日後に岩が戻ります。
7. **木こり**: 木に向かって「きる」。おのが必要です。木は3回切ると倒れ、木材（400種）が出ます。2日後に木が戻ります。
8. **物語**: 章ごとの目標を達成すると、島のどこかに「ひかりのかけら」が現れます。4つ集めると灯台が点灯します。

効果音とBGMは音源ファイルを使わず、ブラウザの Web Audio で生成しています。メニューの「おと」でOFFにできます。

## 開発

```bash
npm install
npm run build        # dist/index.html（単一ファイル）を作成
node tools/check-data.mjs   # 家具・魚・虫・料理・農作物の件数と名前の一意性を検証
node tools/qa.mjs           # ブラウザで起動して画面を撮影（qa-shots/）
node tools/qa-play.mjs      # 釣り・畑・家・料理・睡眠・店・保存を実際に操作して検証
```

`dist/index.html` は依存なしで開けます（Three.js を同梱しています）。

### 構成

| ファイル | 役割 |
|---|---|
| `src/terrain.js` | 地形の高さ場、川・湖・橋、村の配置、植物の配置 |
| `src/scene.js` | 描画: 空、昼夜の光、地形、水、草木、建物、室内 |
| `src/models.js` | 3Dモデル: キャラクター、動物の住民、家具25種、魚、虫、料理、農作物の成長段階 |
| `src/data.js` | 全データ（件数はここで組み合わせて生成） |
| `src/game.js` | 進行: 時間、移動、釣り、虫とり、畑、料理、店、家具配置、住民、物語、保存 |
| `src/ui.js` | 画面: ダイアログ、ポーチ、ノート（図鑑）、店、料理、メニュー、3Dアイコン |
| `src/main.js` | 起動、入力、カメラ、ゲームループ |
| `build.mjs` | esbuild で単一HTMLにまとめる |

### 作り方のメモ

- 3Dモデルは外部のアセットを使わず、プリミティブ（球・箱・円柱など）の組み立てで作っています。アイコンは同じモデルを描いて画像にしています。
- 草と花は大量のインスタンス描画、草木は頂点シェーダで風に揺れます。
- 保存は `localStorage` です。ブラウザのデータを消すとセーブも消えます。
